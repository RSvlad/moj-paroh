# Речник (профил)

Све што корисник или одржавалац чита (текстови апликације, поруке билда и извештаја, назив апликације, називи листова и колона у Sheet-у) налази се у `profiles/paroh/profile.json`. Код, објављени подаци (`CityData`), имена датотека и интерни идентификатори остају неутрални (`territory`, `capital`, `*.territories.geojson`, `data-pipeline/territories.py`): у приказу је `territory` „парохија“, а `capital` „парохијски храм“.

## Шта је у профилу

| Поље | Садржај |
|------|---------|
| `name` | Исти као назив директоријума. |
| `app.title` | Назив апликације: наслов странице, `<h1>`, назив инсталиране (PWA) апликације. |
| `app.cachePrefix` | Префикс кеша прегледача (`<префикс>-data`, `<префикс>-map`); мала слова, цифре и `-`. |
| `sheet.territoriesTab` | Назив листа са парохијама у Sheet-у. |
| `sheet.territoriesTabAliases` | Старији називи тог листа који још раде (уз упозорење у билду). |
| `sheet.territoryColumn` | Називи колоне са идом парохије (први је главни, остали су старији записи). |
| `sheet.capitalKind` | Записи врсте „парохијски храм“ у листу „Тачке“ (мала слова). |
| `forbidden` | Корени речи који се не смеју појавити у приказаним текстовима (проверава тест). Старији називи који се прихватају из Sheet-а су изузети: они су улаз, а не приказ. |
| `text` | Сви текстови које виде корисници и одржаваоци. `{поља}` се попуњавају. |

Профил мора да изрази **сваки** текст, укључујући гранање (падежи, род придева: „Најближи парохијски храм“).

## Који профил је активан

1. променљива окружења `APP_PROFILE`, иначе
2. назив у датотеци `profiles/ACTIVE` (`paroh`).

Профил `paroh` је и подразумевани: јединични тестови (`npm test`) увек њега користе.

## Додавање текста

1. Допишите кључ у `profiles/paroh/profile.json` и користите га са `tr('кључ', { … })` (`src/profile`), `tr('кључ', { … })` из `profiles/load.mjs` (Node) или `tr("кључ", …)` из `data-pipeline/vocab.py` (Python).
2. Тест `profiles/profiles.test.mjs` пада ако кључ недостаје, ако му се поља разликују или ако се кључ не користи у коду.

## Подаци објављени у старијем облику

`profiles/paroh/migrate-previous.mjs` чита раније објављене податке (`upgradeCityData(data)` претвара стари `CityData` у тренутни, `previousGeojsonNames(id)` набраја старе називе датотека са границама); користи га `restore-previous.mjs`. Обришите га када један деплој замени старе податке.
